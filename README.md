# Next Level Gaming & Esports Arena

## Project overview

Mobile application for the XHAW5112 Project Online Experience. It includes a native Android app and a separate React Native app for Expo Go.

## Technologies

- Kotlin, Android SDK and XML layouts
- Gradle
- React Native, Expo SDK 58, Expo Router and TypeScript
- npm

## Main features

- Home and About Us screens
- Gaming packages and individual experiences, including details for all seven offerings
- Fee calculator for distinct offerings, with 0%, 5%, 10% and 15% discounts
- Contact form with local validation; it does not send or store enquiries
- Dark gaming-themed interface and mobile navigation

## Installation

Clone the repository:

```sh
git clone https://github.com/ST10538623/NextLevelGaming-App-POE-3.git
cd NextLevelGaming-App-POE-3
```

For the native app, open the project in Android Studio and allow Gradle to sync. For the Expo app, install Node.js and npm, then install its dependencies:

```sh
cd nextlevel-expo
npm install
```

## Running the application

In Android Studio, select an Android emulator or connected device and run the `app` configuration.

To run the Expo version, start the development server from `nextlevel-expo`:

```sh
npm start
```

Scan the displayed QR code in Expo Go on a device connected to the same network.
